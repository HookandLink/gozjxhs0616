1. `docs/01_정리.md`의 제출 형식과 실제 제출 파일을 비교한다: 파일명, 컬럼명·순서, 행 수, 타입, 결측, 인코딩.
2. SSOT 5절에서 점수가 가장 높았던 구성으로 제출 파일을 만들었는지 확인한다.
3. 문제가 있으면 묻지 않고 바로 고치고, 고친 내용을 SSOT 5절에 기록한다.
4. `README_SUBMIT.md`를 작성한다: 문제 → 접근(병목별 결정과 근거) → 결과 점수 → 한계. 심사위원이 1분 안에 읽을 분량.
